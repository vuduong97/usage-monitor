Saved networks

2.4 GHz only. Up to 4 networks; at boot the device joins the strongest one it can see. Tap a scan result to fill a row. Leave a password blank to keep the stored one.

Device name

The Clawd desktop app finds the clock by this name over mDNS. Running several clocks? Give each its own name (clawd-desk, clawd-shelf). Saving a new name reboots the clock.

Setup hotspot (AP)

The AP appears when no WiFi is configured or the connection fails. Like the WiFi passwords above, leaving the field blank keeps the stored one; tick the box to clear it and leave the hotspot open.

Screen

Colour

The panels shipped in these devices are not the same part, so the same firmware can look warm on one unit and green on another. Turn a channel down to pull that cast out. If red and blue come out swapped, switch the colour order; if the whole screen looks like a negative, tick Invert. Saving applies it immediately, so you can watch the screen while you adjust.

Clock & night mode

Clock: -
Needs internet once to set the clock over NTP. While the window is active it overrides the brightness and auto-brightness above. Times are local to the selected timezone; DST is handled automatically. After a reboot the schedule resumes once the clock re-syncs, so the screen may show normal brightness for a few seconds.

Screen

An attention alert from the desktop app always brings the usage screen forward until it is cleared (or after 2 minutes).

Claude usage

This screen needs the Clawd desktop app on your computer. The clock cannot read your Claude usage on its own: the app reads it and pushes it here (it finds the clock by itself over mDNS). Without it this screen only shows the idle animation.

Push (normal): leave the URL blank; the desktop app posts the usage to the clock. Pull: set the URL to a server that returns the usage JSON and the clock polls it.

Manual update (OTA)

Upload a firmware.bin built from this repo (tools/flash.sh does the same over the command line). The clock reboots when done.

Settings backup

The export is the device's config.json, including WiFi passwords in clear text; treat the file accordingly. Import applies everything and reboots.

Password

Off by default, which leaves the page open to anyone on your network. Turning it on puts the settings page, the API, and the firmware upload behind HTTP digest auth, so the password itself is never sent over the wire. The desktop app's push endpoints stay open, because they only write what the screen shows. There is no password recovery. Forget it and the only way back in is to reflash the device over USB or the UART header, so write it down before you save.
