# smalltv-clawdmeter

Private fork of [giovi321/smalltv-mod](https://github.com/giovi321/smalltv-mod)
(upstream `9201e86`, branch `clawdmeter`) that runs Clawdmeter's screens on a
GeekMagic SmallTV-class clock (ESP8266, 240x240 ST7789, WiFi only). Keep it
private: it embeds Anthropic's Clawd art and the Styrene/Tiempos fonts.

## What it shows

- **Usage**: Clawdmeter's compact 240 px layout: "Current" and "Weekly" cards
  (or Enterprise "Spending" and "Period" with pace), the daemon-fed clock as
  the title, and the whimsical spinner status line.
- **Corner Clawd**: idles, then does acts (waving, dancing, pointing) at a
  pace set by the usage rate.
- **Alert**: the daemon's attention message (`m`) scrolls on the status line
  in a blinking accent frame, and Clawd alternates waving and pointing. It
  clears on `x` or after 2 min.
- **Idle**: no data for 90 s shows the cloud mini animation plus
  "Listening… / No data…".
- **Splash**: the 17 official Clawd animations full screen (60x60 stage,
  4 px cells). Each one plays intro → loop → outro, and the walkers cross the
  stage. They are picked by usage-rate group and rotate every 20 s, or you can
  pin one.

Settings live in the web UI, under **Usage → Clawdmeter**:

- **Screen**: Auto (usage while data is live, splash otherwise), Usage, or Clawd.
- **Animation**: by usage rate, or a fixed one.

## Build / flash

```sh
pio run -e smalltv_clawd                   # default env; .pio/build/smalltv_clawd/firmware.bin
```

Flash `firmware.bin` over the device's `/update` page. If the stock firmware
rejects the image, use the loader first (`pio run -e smalltv_loader`, see
`platformio.ini`). The GitHub self-updater is disabled in this build because
upstream releases would replace the Clawd UI.

Never change `board_build.ldscript` (flash/LittleFS layout) after the first flash.

## Data

The Clawdmeter macOS daemon pushes over HTTP. Add these lines to
`~/.config/claude-usage-monitor/config`:

```ini
http_targets = <device IP>
ble = off            # if there is no Bluetooth Clawdmeter
```

`POST /api/usage` accepts the Clawdmeter payload: `s sr w wr st ok acct tp rd
t tf m x`. `ok:false` is accepted (200) and the screen goes idle once data is
stale. `c`/`b` (chime) are ignored. The old pull mode (Usage daemon URL) still
works.

## Heap watch

`GET /api/heap` needs no auth and is read only. It returns `heap`, `maxblk`,
`minHeap`, `minMaxblk`, `frag`, `uptime`, `reset`, `version`, `splash` and
`anim`. For a 24 h check:

```sh
while sleep 60; do curl -s http://<ip>/api/heap; echo; done >> heap.log
```

Target: `minHeap` ≥ 20 KB and no unexpected `reset` over 24 h.

## Code map

| Path | Role |
|---|---|
| `src/features/clawd/clawd_anims.h`, `clawd_fonts.h` | Generated by `tools/clawd_assets.js` from Clawdmeter's `firmware/src` (`node tools/clawd_assets.js <Clawdmeter>/firmware/src`). 4-bit animations (209 KB) and subset 4 bpp fonts with kerning, all PROGMEM. |
| `ClawdDraw.*` | No framebuffer. Each region is composed in 4-row bands (1,920 B buffer): background, anti-aliased rounded shapes, then anti-aliased text. Each band is one SPI push, so redraws don't flicker. Pixel-art cells are diffed per grid row. |
| `ClawdAnim.*` | Port of `splash.cpp`: player, splash with walkers and rate groups, corner mascot, mini. |
| `ClawdRate.*` | Port of `usage_rate.cpp`. |
| `ClawdUi.*` | Screens, views, alert and status line. |
| `features/usage/UsageMode.cpp` | Glue: Arduino_GFX surface plus ticking. |
| `tools/clawd_preview/run.sh` | Desktop build of the same renderer. Writes PNG screenshots of every screen and animation to `.pio/clawd_preview/` for visual QA without hardware. |

Measured (`pio run -e smalltv_clawd`):

| Build | Static RAM (of 81,920 B) | Flash (of 1,044,464 B) |
|---|---|---|
| `smalltv_clawd` (this fork, recommended) | 46,904 B (57.3%) | 838,533 B (80.3%) |
| `smalltv` with every feature plus Clawd (not recommended) | 66,472 B (81.1%) | 982,985 B (94.1%) |
| Upstream `smalltv` baseline | 61,824 B | 776,225 B |

On the ESP8266, static RAM and heap share one 80 KB arena. Use `smalltv_clawd`.
The ESP32 envs were not rebuilt after this port.
