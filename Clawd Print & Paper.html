Clawd Print & Paper
Clawd desk clock · usage screens · batch B of J

Batch B · Print & paper

Ten styles, #11 to #20, each drawn in the four sample states. Every screen is built only from the firmware primitives, and the self-check table at the end is computed from the same element lists that draw the screens.

  • Fonts: one fixed weight per font file (Sans 12-20 Medium, Sans 24/28/48 Bold, Serif Medium, Mono 18 Medium, Mono 32 Bold). Text y = top of the em box. "5H at least 28 px" read as font size.
  • Colours are snapped to exact RGB565 values in the mock; every pair in a design differs by 8+ levels in at least one channel.
  • Patterns draw only the stripe pixels; the gaps are left unpainted (CSS shows them as transparent).
  • State colours: one element may swap colour per state (hot, whot, fresh, no data), as in the example spec card. Everything else state-specific is a separate element shown only in that state.
  • Gauges: n-segment gauges light segment k when value ≥ round((k+0.5)×100/n).
  • Counts: every element is counted once for the whole pack, including the ones only shown in one state. Clawd counts 1 per layer (body, eyes, outline).
